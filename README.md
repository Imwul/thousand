# Across a Thousand Dead Worlds

종이 캐릭터 시트와 함께 사용하는 Across a Thousand Dead Worlds 개인용 오라클·솔로 GM 작업대.

```sh
npm ci
npm run dev -- --port 5180
```

<http://127.0.0.1:5180/>에서 연다. 공개 주소는 <https://imwul.github.io/thousand/> 이다. Node 22 이상. 런타임 외부 API나 유료 생성 서비스가 필요하지 않다.

```sh
npm test
npm run audit:play
npm run build
```

기본 플레이용 표 265개(원문 범위가 중복된 감정 하위 표 1개는 직접 확인)와 상황별 굴림 31개를 제공한다. 결과는 한국어 요약 또는 원문 영문이며 출처 쪽수·원래 주사위·당시 맥락을 함께 저장한다. 수록 시나리오 두 편의 전용 표는 사용자 요청으로 제외했다.

캐릭터 시트 수치를 관리하지 않는다. 피해·Stress·시간·물품은 종이에 기록한다. 작업대 위의 탐사 막대는 장소·인원·반전처럼 굴림에 쓰는 맥락만 보여 준다. 곁질문은 열린 보고서를 바꾸지 않고 예/아니오를 새 기록으로 남긴다. 이어서 굴릴 상황은 이번 결과에 맞추되 이미 있는 절차만 연다. 상황 목록은 질문·항해·시설·행성·인물·전투·정거장으로 묶는다. 보고서 제목 아래에는 저널에 적을 문장과 그 문장만 복사하는 버튼, 시트에 적을 사실, 착륙 칸의 10×10 배치, 잠긴 문과 해킹 선택을 둔다. 예/아니오에 입력한 질문은 그 굴림의 저널 문장에만 붙는다. 잠긴 문의 선택 안내와, 예상대로 시작한 장면의 이어가기 안내는 저널 문장에 넣지 않는다. 헥스 탐사에서 생물군계 위험·장애물 표가 굴려졌으면 그 결과를 저널 문장에 붙인다. 발견물에서 유물이 나왔거나 조우가 이미 굴려졌으면 그 결과도 같은 문장에 붙이고, 인쇄된 표제 문장은 바꾸지 않는다. 잠긴 문의 효과와, 열린 뒤 문 너머의 결과도 저널 문장에 넣는다. 헥스에서 Àrsaidh 시설을 찾으면 도착표는 다시 굴리지 않고, 용도·규모·위험과 탐사 한도만 새 기록으로 굴린다. 작업대의 종이 체크와, 질문이 없을 때의 곁질문 칸은 두지 않는다. 시간트랙은 자동으로 진행하지 않는다. 잠긴 문, 해킹, 독성 생물군계의 금속 구체, 헥스에서 찾은 Àrsaidh 시설은 플레이어가 선택한 뒤에만 후속 굴림을 새 기록으로 만든다. 원문 오기는 추정해서 고치지 않는다.

데이터는 IndexedDB `thousand-worlds-logbook`에 캠페인별로 저장된다. 새로고침 뒤 복원된다. JSON 백업과 검증 후 가져오기, Markdown 내보내기를 제공한다. 서버·계정 동기화는 없다. 다른 브라우저·프로필·호스트에서는 백업을 가져와야 한다.

PC, 3440px 울트라와이드, 모바일 레이아웃을 포함한다. 보고서 Hahmlet Variable, 영문 제목 Barlow Condensed Black, 조작부 SUIT Variable을 사용하며 OFL을 동봉했다.

원문 PDF와 추출 캐시는 앱 소스·배포물에 포함하지 않는다. 엄폐도와 Guardian 능력치의 원문 도해는 개인용 사이트의 빠른 참조에 사용한다. 원작 © Blackoath Entertainment. 비공식 개인용 팬 도구.

구조는 `src/data`(원문·표), `src/domain`(모델), `src/generators`(난수·조건부 절차), `src/storage`(검증·기록), `src/components`(화면)로 나눈다. 기존 MÖRK BORG Reference Desk의 책임 분리를 참고했으며 UI는 별도로 디자인했다.
