# Across a Thousand Dead Worlds

종이 캐릭터 시트와 함께 사용하는 Across a Thousand Dead Worlds 개인용 오라클·솔로 GM 작업대.

```sh
npm ci
npm run dev -- --port 5180
```

<http://127.0.0.1:5180/>에서 연다. 공개 주소는 <https://imwul.github.io/thousand/> 이다. Node 22 이상. 런타임 외부 API나 유료 생성 서비스가 필요하지 않다.

```sh
npm test
npm run audit:play
npm run audit:ko
npm run build
```

기본 플레이용 표 265개(원문 범위가 중복된 감정 하위 표 1개는 직접 확인)와 상황별 굴림 33개를 제공한다. 결과는 한국어 설명(고유명은 원문, 생물명은 병기)이며 출처 쪽수·원래 주사위·당시 맥락을 함께 저장한다. 수록 시나리오 두 편의 전용 표는 사용자 요청으로 제외했다.

캐릭터 시트 수치를 관리하지 않는다. 피해·Stress·시간·물품은 종이에 기록한다. 작업대 위의 탐사 막대는 장소·인원·반전처럼 굴림에 쓰는 맥락만 보여 준다. 곁질문은 열린 보고서를 바꾸지 않고 예/아니오를 새 기록으로 남긴다. 이어서 굴릴 상황은 이번 결과에 맞추되 이미 있는 절차만 연다. 상황 목록은 질문·항해·시설·행성·인물·전투·정거장으로 묶는다. 결과는 항목명과 값을 분리한 칸으로 표시한다. 생물과 NPC의 능력치·전투 수치, 시설의 탐사 한도, 시간·소모품은 각각의 수치 칸으로 읽는다. 특성·재능·환경 효과·부상 등 설명형 값도 제목 띠 아래 별도 영역에 배치하며, 피해 주사위·보정치를 강조한다. 복사용 저널 문장과 보고서 복사 버튼은 두지 않는다. 수치는 능력치·전투·공격 순으로 묶고 특성은 그 아래 행별로 배치한다. 같은 행의 칸은 높이를 맞추며, 홀수로 남은 칸은 전체 폭을 쓴다. 3440px에서는 결과 양옆의 패널 폭과 간격을 대칭으로 맞추고, 모바일에서는 수치 칸을 재배치한다. 1180px 이하에서는 상황 목록을 접어 결과 폭을 확보한다. 유물별 감정은 정산 아래 한 표에 모으고, 현재 적 참조는 전투에 관련된 상황에서만 펼친다. 작은 화면은 굴림 후 옵션을 접고 결과를 먼저 확인하게 한다. 착륙 칸의 10×10 배치는 필요할 때 펼치는 참조이며, 생물의 외형·이름 굴림과 개인 메모도 접힌 참조로 남긴다. 현재 적의 상세 보고서를 열었을 때는 옆에 같은 참조를 중복 표시하지 않는다. 잠금과 해킹 선택은 필요한 시점에만 표시한다. JSON 백업과 Markdown 내보내기는 백업 메뉴에 남긴다. 헥스에서 Àrsaidh 시설을 찾으면 도착표는 다시 굴리지 않고, 용도·규모·위험과 탐사 한도만 새 기록으로 굴린다. 작업대의 종이 체크와, 질문이 없을 때의 곁질문 칸은 두지 않는다. 시간트랙은 자동으로 진행하지 않는다. 잠긴 문, 해킹, 독성 생물군계의 금속 구체, 헥스에서 찾은 Àrsaidh 시설은 플레이어가 선택한 뒤에만 후속 굴림을 새 기록으로 만든다. 원문 오기는 추정해서 고치지 않는다.

데이터는 IndexedDB `thousand-worlds-logbook`에 캠페인별로 저장된다. 새로고침 뒤 복원된다. JSON 백업과 검증 후 가져오기, Markdown 내보내기를 제공한다. 서버·계정 동기화는 없다. 다른 브라우저·프로필·호스트에서는 백업을 가져와야 한다.

PC, 3440px 울트라와이드, 모바일 레이아웃을 포함한다. 보고서 Hahmlet Variable, 영문 제목 Barlow Condensed Black, 조작부 SUIT Variable을 사용하며 OFL을 동봉했다.

원문 PDF와 추출 캐시는 앱 소스·배포물에 포함하지 않는다. 엄폐 배치 도해를 빠른 참조에 사용하며, 수호자와 추적 위협은 한국어 고정 능력치 카드로 제공한다. 원작 © Blackoath Entertainment. 비공식 개인용 팬 도구.

구조는 `src/data`(원문·표), `src/domain`(모델), `src/generators`(난수·조건부 절차), `src/storage`(검증·기록), `src/components`(화면)로 나눈다. 기존 MÖRK BORG Reference Desk의 책임 분리를 참고했으며 UI는 별도로 디자인했다.

조우에서 「이 조우의 적 생성」을 누르면 같은 종의 난도별 카드를 생성한다. 행동·전투 버튼은 해당 적의 역할과 매복 여부를 이어받는다. 종을 조우 슬롯에 연결하면 다음 조우에서도 원형을 재사용한다. 현재 적 참조와 전투 중 판정은 보고서 옆에 둔다. 새 시설·야외 생물군계는 별도 맥락으로 보관하며, 탐사 맥락에서 이전 장소를 복원할 수 있다. 야외 시간트랙 초기화는 추가 시설 매복을 굴리지 않는다. 귀환 항해는 정거장과 일괄 유물 감정으로 이어진다. 과거 기록과 기존 JSON 백업을 계속 읽고, 가져오기 시 적·장소·인물 참조도 함께 재연결한다.

인접 생물군계 전환은 경계에 도달했을 때만 사용하며, 현재 환경의 장비 조건·방사선·독성 효과를 보고서에 표시한다. 미정인 해킹 시스템 난도는 선택하면 D6으로 정한다. 원문 범위가 겹친 감정 하위 표는 주사위 없이 직접 골라 기록할 수 있다.
