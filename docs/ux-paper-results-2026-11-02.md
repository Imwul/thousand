# 종이 전사 중심 결과 화면 · 2026-11-02

사용자는 디지털 저널을 사용하지 않으며, 굴림의 각 값을 종이에 옮긴다. 기존의 「저널에 적을 문장」은 사용자 피드백으로 폐기한다. 이 결정은 2026-10-31 설계 문서의 문장 중심 결정을 대체한다.

적용 관점: BMAD UX Designer와 web-design-guidelines. 설치된 UX 디자이너의 관점과 현재 코드 검토를 사용했다. 별도의 사용자 인터뷰나 전체 BMAD 자동 설계 워크플로를 실시한 것으로 간주하지 않는다.

## 화면 결정

- 모든 결과는 항목명과 값이 대응하는 정의 목록으로 표시한다. 긴 설명도 제목 띠와 독립된 값 영역을 가진다.
- 능력치 여섯 개, 전투 수치, 공격과 피해는 독립된 수치 칸이다. 0과 인쇄된 대시, 조건부 공격값을 그대로 보존한다.
- 특성·재능은 이름과 효과를 분리하며 원래 설명에 있는 피해 주사위, 보정치, 횟수를 강조한다. 설명을 추정하거나 새 규칙으로 요약하지 않는다.
- 일반 결과, 행성, 탐사지, NPC, 부상, 전투 행동, 수동 표도 같은 값 영역을 사용한다.
- 시설의 자원·유물 탐사 한도는 실제 소지 개수와 구분한다. 귀환 정산은 항목·수량·단가·금액·합계 표다.
- NPC는 능력치와 기본 상처·방어를 먼저 표시한다. 이름 조각은 접힌 생성 근거에 남긴다.
- 생물은 수치와 효과를 우선 표시한다. 외형과 이름 근거는 펼칠 수 있다. 같은 종의 혼합 난도 조우는 난도와 개체 수를 유지한 별도 카드다.
- 현재 적의 원본 보고서를 보고 있을 때 같은 내용을 옆에 반복하지 않는다. 다른 판정으로 이동하면 적 참조를 다시 표시한다.
- 3440px에서는 수치와 효과를 병렬로 배치한다. 모바일에서는 능력치를 3열로 배치하고 값의 가로 넘침을 막는다.
- 결과가 열리면 2500px 미만 화면의 옵션을 접는다. 굴림 버튼은 항상 접근 가능하며 접힌 폼의 옵션도 유지한다.
- 복사 버튼과 합쳐진 저널 문장은 제거한다. 메모·굴림 근거·JSON 백업·Markdown 내보내기와 저장된 원본은 유지한다.

## 검증 기준

33개 상황의 여러 분기에서 원래 항목 값이 유지되는지, Guardian 16개 난도 조합과 추적 위협 6종의 수치 및 대시가 맞는지, 혼합 조우·정산·현재 적 참조와 후속 행동이 연결되는지 확인한다. 브라우저에서는 320·390·768·1440·3440px의 줄바꿈과 실제 굴림 흐름을 확인한다. 사용자가 종이와 함께 플레이한 사용성 실험을 대신하는 검증은 아니다.
