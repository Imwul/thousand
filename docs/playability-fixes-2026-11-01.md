# 종이 시트 옆의 솔로 GM 작업대 — 수정·검증

사용한 스킬은 PDF(제공된 원문 대조)와 web-design-guidelines(UI·접근성 검토)다. 기본 플레이용 표 265개와 상황 33개를 제공한다. 시나리오 전용 표는 제외한다. 수치·소모품·시간트랙과 저널은 종이에서 관리한다.

| Before | After | Why |
| --- | --- | --- |
| 추적 위협의 이름·행동만 제공 | 6종의 고정 능력치·이동·표적 우선순위·회복 반응·고유 효과 제공 | 추적 위협 전투에 필요한 참조 완성 |
| 조우 상세가 이전 생성 옵션과 기록을 엶 | 조우에 연결된 유형·크기와 개체 구성 사용, 같은 종의 난도별 카드 생성 | 같은 적을 계속 사용 |
| 잠복형 아난시 다음 행동이 돌격형 | 각 카드의 역할로 행동·전투 실행 | 잘못된 행동 표 방지 |
| 조우 슬롯에 유형 문자열만 보관 | 저장한 종 원형을 연결해 이름·외형·특성을 재사용 | 재조우의 정체 보존 |
| 한 헥스의 후속 조우가 앞 조우를 덮음 | 서식지·추가 조우의 개별 구성과 자식 카드 보존 | 독립 조우 누락 방지 |

| 이어서 굴리기가 예전 맥락을 재사용 | 채택한 장소와 최신 지형·조우 목록 사용. 재굴림은 원래 스냅샷 사용 | 진행과 재굴림의 의미 보존 |

| 귀환 감정은 유물 하나씩 | 귀환 항해와 일괄 감정·자원·기록 보수 계산 연결 | 귀환 흐름 완성 |
| 생물군계 경계는 표 검색 필요 | 인접 생물군계 절차, 단일 생물군계 예외, 새 활동도와 환경 효과 | 야외 탐사 연결 |

| 일반 질문과 곁질문 입력이 상시 중복 | 다른 보고서에서 곁질문을 펼칠 때만 입력 표시 | 중복 조작부 축소 |
| 보고서 큰 제목·부제·저널 문장 중복 | 저널 문장 중심, 세부 표·외형 접기 | 읽을 양 줄이기 |

NPC의 이름을 상세·대화·감정·정보에 연결한다. 원래 NPC 상세는 다시 열며 새 인물을 무조건 생성하지 않는다. 캠페인 전환 시 대기 중인 후속 연결을 초기화한다. 기존 영어 기록·수호자 도해 기록·기존 백업을 계속 읽으며, 가져오기 때 장소·종·행동·인물 연결 ID를 함께 재매핑한다.

## 검증

- 자동 테스트 **65개 통과**, 실패·취소 0. 이전 로컬 UI 테스트 정지는 의존성 재설치 후 재현되지 않는다. 주입한 테스트 HTML의 외부 스크립트 로딩을 끄고 파일별 제한 시간을 추가했다.
- **9,900회** 생성, 문 후속 **654회**, 해킹 후속 **1,050회**, 조우 카드 후속 **284회** 통과. 원시 집계는 `play-verification.json`에 있다.
- 265개 표의 주사위 범위 검사, 번역 86개 표·1,022행의 숫자·주사위 토큰과 미번역 설명 검사 통과.
- 원문 p.302/304/306/308/310/312의 고정 능력치를 렌더링해 수치·대시·예외를 시각 대조했다. 생물군계·사기·회복·해킹·감정 표 관련 본문도 대조했다.
- 실제 브라우저: 아난시 → 잠복형 행동, 추적 위협 → 확정 매복 전투, 혼합 난도 수호자 카드 → 슬롯 저장, 시설 → 새 행성 → 야외 시간 초기화 → 시설 복원, 귀환 → 유물 4개 일괄 감정, 같은 NPC의 대화, 관련 표에서 후속 절차, 인접 생물군계 → 새 맥락, 중복 범위 감정의 수동 저장, 미정 해킹 난도와 노드 생성 확인.
- 320·390·768·1024·1440·1920·2560·3440px에서 문서 가로 넘침 없음. 모바일 → 데스크톱으로 크기를 바꿨을 때 상황 메뉴가 다시 열리는 것도 확인했다. 콘솔 오류·경고 없음.
- JSON의 추가 가져오기·참조 재매핑·손상 자료 거부·원본 불변은 저장 모듈 테스트로 검증했다. 이번에는 실제 파일 선택기를 통한 백업 전송과 물리 모바일 기기의 터치를 시험하지 않았다. 장기 캠페인 완주 시험과도 구분한다.

UI 재검토에서는 모달 스크롤 경계, 이미지의 고유 크기, 긴 표 목록 렌더링, 모바일 상황 메뉴, 기존 값의 재사용 표기도 보완했다. 기본 플레이 흐름에서 새로 확인한 누락은 위 항목까지 반영했다.
