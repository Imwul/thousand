# 플레이 준비 재점검 — 2026-11-02

이전 점검 이후의 재감사. 시나리오 전용 표는 제외한다. 종이 캐릭터 시트와 저널을 사용하는 흐름을 유지한다.

## 화면 설계 기준

- 색: 바탕 `#0b2024`, 깊은 바탕 `#07191d`, 결과지 `#e3e6da`, 결과 글자 `#243a39`, 탐색 `#56dcff`, 실행 `#ff7359`. 기존 선택 상태의 노란색은 유지한다.
- 글꼴: Hahmlet은 결과 본문, SUIT는 조작·수치, Barlow Condensed는 게임 제목. 기존 역할별 크기를 유지한다.
- 기존 넓은 화면: `탐색 | 옵션 | 결과 | 후속 | 기록`의 5개 영역. 보고서의 수학적 중심은 맞지만 작업 영역이 과도하게 분산된다.
- 채택: `탐색 | 옵션 + 결과 | 후속 + 기록`. 좌우 보조 영역은 같은 너비. 보고서 내부는 독립된 세로 2열을 유지한다.
- 13인치 iPad와 좁은 화면은 탐색을 접고 한 흐름으로 배치한다. 충분한 결과지 너비가 확보되면 내부 2열을 유지한다.
- 전체 콘텐츠의 최대 너비와 중심선을 통일하고 스크롤바 양쪽 여백을 확보한다. 긴 문장은 항목 안에서 자연스럽게 줄을 바꾸며 가로 스크롤을 만들지 않는다.

기존 SF 탐사 기록지와 수기 플레이 요구를 검토한 뒤, 색·폰트의 전면 교체 없이 정보 배치와 정렬에 집중하기로 했다.

## 룰북 대조 범위

Core 2024의 기본 규칙·탐사·생물·정거장·장비 범위(p.1–408)를 대상으로 표 제목과 주사위 표기를 기존 목록과 대조했다. p.409 이후 수록 시나리오 전용 표는 요청에 따라 제외했다. 265개 표(자동 264개, 원문 중복 범위로 수동 선택 1개)가 유지되며, 이번 재점검에서는 누락된 독립 표 이름보다 표 밖의 조건부 확률과 보조 주사위 연결에서 결함을 찾았다. 이 대조가 모든 문장의 의미를 완벽하게 검증했다는 뜻은 아니다.

기존 8개 룰북 보조굴림에 11개를 추가했다: 자동 포탑 탄약, 근접전 사격의 잘못된 대상, 구역 전투 엄폐, 기생체 잠복·성숙, 가스 지속 시간, 방사선 노출 잔여 시간, GPS 고장 후 누적 함선 수색, 신경 손상 행동 불가, 산성 능력 장비 파괴, 해류 방향. 수치뿐 아니라 탄약 남음/고갈·함선 발견 같은 적용 결과를 별도 항목으로 표시한다. 관련 상황에서는 보조굴림 버튼으로 바로 접근한다.

원문이 50%만 제시하는 판정은 앱에서 D6 1–3/4–6으로 구현했음을 설명한다. 해류의 여섯 방향은 종이 지도에서 사용자가 번호를 정한다. 인물 능력치 판정, 자원 차감, 장비 선택은 종이 시트에서 처리한다.

## 저장 기록

규칙 버전은 `atdw-core-2024-logbook-ko-5`. 기존 기록의 주사위와 결과를 다시 계산하지 않는다. ko-4 생물 기록에는 이미 수정된 장갑/방어 규칙의 경고를 다시 띄우지 않는다. 새 함선 수색 입력은 예전 백업에 없으면 1로 초기화한다.
