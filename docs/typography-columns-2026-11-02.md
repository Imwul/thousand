# 두 열과 글자 크기 정리

종이 시트에 옮겨 적는 흐름을 유지하면서 넓은 결과를 같은 폭의 세로 두 열로 복원했다. 앞선 행별 통합 배치 대신 다음 구획을 쓴다.

- 생물: 왼쪽 능력치·전투·공격·공격 조건, 오른쪽 특성·능력·독 상태 참조.
- NPC: 왼쪽 능력치·전투·재능, 오른쪽 인물 묘사.
- 행성: 왼쪽 행성·생물군계, 오른쪽 첫인상·탐사 조건.
- 시설: 왼쪽 도착·용도·규모·활동·위험·탐사 한도, 오른쪽 과거·인상 등.
- 정산: 왼쪽 정산 내역·합계, 오른쪽 유물별 감정.
- 다른 복합 결과: 그룹을 유지하며 두 열로 분배. 단일 그룹의 항목은 기존 값 칸을 유지한다.

보고서 내부 폭 720px 이상에서 1:1 두 열을 쓰고, 그 미만에서는 왼쪽 열부터 위아래로 읽는다. 열 제목과 첫 카드의 시작선을 맞춘다. 수치 영역 안에서 전투와 공격을 다시 비대칭으로 분할하지 않는다.

`src/typography.css`가 유일한 글자 크기 정의다. 기존 스타일의 내용 길이·모니터 폭·참조 패널별 크기 덮어쓰기를 제거했다.

| 역할 | PC | 모바일 |
| --- | --- | --- |
| 결과 제목 | 28px | 24px |
| 구획 제목 | 16px | 16px |
| 항목명 | 12px | 12px |
| 값·설명·효과·조건 | 16px | 15px |
| 수치·주사위 | 26px | 24px |
| 출처·굴림 이력 | 11px | 11px |
| 버튼·설정 | 14px | 14px |

특성 이름은 같은 글자 크기의 굵기로 구분한다. 설명 속 보정치·주사위도 글자를 키우지 않고 색과 굵기로 강조한다. 수치가 아닌 문장은 본문 크기를 쓰며 문장 길이로 크기를 정하지 않는다. 저장 기록·굴림값·상태·메모는 변경하지 않는다.

검증: 자동 테스트 74개, 265개 표 빌드 검사 통과. 기존 저장 기록 33종을 1440/390px에서 확인하고, 주요 결과 6종을 320/390/768/1024/1440/2560/3440px에서 확인했다. 결과 본문 크기, 열 폭, 가로 넘침 및 값 잘림을 검사했다. 위협 참조와 백업 창도 320/390/1440px에서 확인했다.
