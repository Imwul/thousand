# Core 룰북 대조와 순례 플레이 점검

기준: 사용자가 제공한 Across a Thousand Dead Worlds Core Rulebook 2024. 본문 p.1–408을 대상으로 주사위·확률·후속 판정 지시를 검색하고, 관련 규칙과 기존 265개 표 및 생성기를 대조했다. 수록 시나리오 전용 표는 요청에 따라 제외했다. 265개는 앱에 등록된 표의 수이며 모든 본문 규칙이 자동화됐다는 뜻은 아니다.

종이 캐릭터 시트·저널을 사용하는 흐름을 유지한다. 앱은 GM 결과와 원주사위, 선택한 조건을 저장한다. PC 능력치, 장비 목록, 소모품, 상처, 시간트랙은 종이에 반영한다.

## 실제 순례

테스트용 로컬 캠페인에서 UI 버튼을 사용했다. 배포 사이트의 사용자 기록은 수정하지 않았다.

1. 알려진 목적지로 1주 항해 → 도착 → 소행성 내부 금고 생성.
2. 장소 맥락 채택 → 수직 구조의 등반 16피트 → 새 구역에서 유물 2개 발견.
3. 유물 활성화 → 정신의 문 생성 → 방화벽 1–8에서 안쪽 선택 → 접근 노드 6으로 성공.
4. 문 효과 D20을 곁굴림 → 결과 4를 버튼 아래에서 확인. 원래 문 보고서 유지.
5. 스트레스 20 → 강박·트라우마 → 정예 토착 생물 생성.
6. 적 카드에서 전투 준비 → 상대 기습 상태와 PC 자유 배치 확인 → 같은 잠복형 적의 행동 → 부상.
7. 귀환 항해 → 유물별 감정 → 정산 합계 180 DC 확인.
8. 명중 부위 보정: 원주사위 5, 보정 +1, 합계 6 → 몸통 결과 확인.

별도 저장 기록을 가져와 금속 상자, 공포 판정 실패, 수중 포식자 분기도 눌러 확인했다. 이미 처리한 분기는 기존 결과를 다시 열며 새 주사위를 자동으로 만들지 않는다.

희귀 장비 입수에서 뇌물 +14와 700 DC, 실험 장비로 전환했을 때 무관한 옵션이 사라지는 것도 확인했다. 실제 JSON 내보내기 파일의 3개 캠페인·29개 기록을 읽어 검증하고 새 ID로 복원했을 때 29개가 유지되는 것을 확인했다. 새로고침 후 원본 보고서와 곁굴림도 남아 있었다.

## UI·태블릿 검토

`web-design-guidelines` 스킬의 [검토 기준](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)을 적용했다. 발견 사항과 수정 위치:

- src/components/render.js:69 — 효과 결과가 아래쪽 보조 패널에만 보이던 문제. 효과 버튼 바로 아래에도 최근 값 3개 표시.
- src/domain/play.js:61 — 조건부 조우와 경보문 실패 후 다음 행동을 조우 처리부터 안내.
- src/components/render.js:182 — 보조굴림 결과에서 주·DC 단위가 빠지던 표시 보완.
- src/components/result-fields.js:34 — 보정 표의 원주사위·보정·합계를 각각 읽을 수 있는 수치 칸으로 제공.
- src/styles.css:357 — 태블릿/터치 화면의 작은 버튼·선택·참조 링크를 최소 44px로 확대.
- src/styles.css:349 — 좁은 화면에서 탐사 선택 라벨이 세로로 쪼개지던 문제를 한 줄로 수정.
- src/typography.css:76 — 태블릿 분할 화면에서도 본문 16px 유지. 입력 필드는 16px로 표시.

레이아웃은 같은 폭의 세로 두 열을 유지한다. 보고서 내부 폭이 720px 미만이면 위아래 한 열이 된다.

## 자동 검증

- 자동 테스트 93개 통과. 자연 1, 확률 경계, 후속 분기, 원형 재사용, 원본 보존, 보정 및 백업 왕복 포함.
- 36개 절차를 각각 300회: 총 10,800회 생성.
- 잠금 후속 654회, 해킹 후속 1,050회, 조우 카드 300회, 조건부 후속 107회, 효과 주사위 1,582회 검사.
- 265개 표 등록: 자동 굴림 264개, 원문의 범위가 겹치는 감정 세부표 1개는 직접 선택.
- 번역 자동 검사: 86개 번역 표·1,022개 행에서 숫자 누락/영문 설명 잔존 탐지 없음. 이는 번역 의미 전체의 무오류를 보증하는 검사는 아니다.
- 프로덕션 빌드 및 diff 공백 검사 통과.

## 자동 확정하지 않은 규칙

아래는 표 누락과 구별해야 한다. 앱에 효과나 표는 있지만 원문에 없는 해석을 자동 확정하지 않았다.

- p.247 감정 세부표의 1–2 범위 중복: 두 결과 중 직접 선택.
- p.168 고정 사건 13의 Swarm (Hard): 일반 적 난도 4단계와의 대응이 명시되지 않아 임의로 정예로 변환하지 않음.
- p.336 공부에서 D20이 기술 값과 같을 때: 원문은 높음/낮음만 규정. 프리셋에 판단 필요 표시.
- 표 보정 후 인쇄 범위를 벗어난 값: 상한/하한으로 몰아넣지 않고 원값·합계와 판단 필요를 표시.
- Carapace 중복 획득: 원문에 중첩 규정이 없다. 앱은 +3을 한 번 반영하고, 중복일 때 그 관례와 추가 판단 필요를 표시.
- 미지 목적지에서 ±D4주를 도착 확률식에 연결하는 방법, 우주 이상 현상 1의 진행 없는 1주와 주말 사건·도착 판정의 선후는 원문이 명확히 정하지 않는다. 항해 시간은 종이에서 조정해야 한다.
- 캐릭터의 소지품 중 무작위 파괴 대상, 적용 가능한 재능, 기술 판정, 장비·소모품의 실제 소유량은 종이 시트를 보고 결정한다. 일반 주사위와 효과 주사위는 지원하지만 PC 시트까지 자동 관리하지 않는다.

기존 기록은 다시 계산하지 않는다. 이전 방식으로 생성한 일반 생물에는 안내를 붙이고, 수정된 생성 규칙은 새로 만든 기록부터 적용한다.
